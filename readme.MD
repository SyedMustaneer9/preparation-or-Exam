# 🇵🇰 PakStudy AI Exam Prep

An interactive AI-powered exam preparation web application built for Pakistani **Matric (9th/10th)** and **Intermediate (11th/12th - FA/FSc/ICS)** students. 

Students can upload their textbook chapters (PDF or TXT), generate board-pattern exam questions, test their knowledge, and receive instant evaluations and model answers explained in **English**, **Roman Urdu**, or **Urdu (اردو)**.

---

## 🚀 Features

* **Textbook Chapter Upload:** Supports standard PDF and TXT textbooks from any Pakistani educational board (FBISE, Punjab, Sindh, KPK, Balochistan, etc.).
* **Board-Style Question Generation:** Automatically generates short questions, long/detailed questions, or MCQs tailored to Pakistani exam patterns using the **Groq API** (`llama-3.3-70b-versatile`).
* **Interactive Evaluation:** Students write answers in their own words and receive detailed feedback, scoring, and ideal model answers.
* **Multilingual Explanations:** Get explanations and feedback in **English**, **Roman Urdu**, or **Urdu script (Nastaliq)**.

---

## 🛠️ Tech Stack

* **Frontend & App Framework:** [Streamlit](https://streamlit.io/)
* **AI Engine:** [Groq API](https://groq.com/) (Fast inference with Llama 3 models)
* **File Processing:** `PyPDF2`
